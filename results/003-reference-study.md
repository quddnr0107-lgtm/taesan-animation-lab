# 실험 003 — 똘똘이 참고 장면 재현

![CPU에서 렌더링한 대표 이미지](003-hero.jpg)

## 참고

KBS 공개 에피소드 썸네일을 시각적으로 관찰했다. 원본 영상·캐릭터 모델·텍스처·음성은 저장소에 포함하지 않았다.

참고 장면: https://mediafactory.play.kbs.co.kr/vod/2021/11/09/618a474ea0e8172c1abeaf95/thumbnail/618a474ea0e8172c1abeaf95_edit_1_1636455028297.jpg

## 대표 이미지 검증

- 실행: https://github.com/quddnr0107-lgtm/taesan-animation-lab/actions/runs/40148301942
- 768×432, EEVEE 64 samples, 실제 대표 프레임 렌더 및 눈으로 확인
- CPU 소프트웨어 OpenGL: llvmpipe, Accelerated: no
- 장면 생성과 대표 이미지: 36.82초, 최대 RSS 614,004 KiB
- 이 실행은 **정지 이미지 1장**이다. 최초 report.json의 72프레임·3초는 계획값이 잘못 섞인 메타데이터였으며, 후속 코드에서 정지/동영상 모드와 실측 프레임 수를 분리했다.

## 구현한 요소와 차이

| 요소 | 이번 구현 | 남은 차이 |
|---|---|---|
| 얼굴 | 볼·턱 실루엣, 눈 여러 층, 속눈썹, 눈썹, 입술 | 원본 얼굴 형태·표정 리그와 다름 |
| 머리 | 여러 곱슬 덩어리, 앞머리, 묶음, 리본 | 덩어리가 굵고 머릿결·실루엣이 다름 |
| 옷·손 | 붉은 상의, 주름치마, 줄무늬, 주머니, 손가락 | 옷감·손 관절·변형의 섬세함 부족 |
| 배경 | 바닥·책장·창문·주방 장난감·화분 | 실제 세트의 비율·소품·빛과 다름 |
| 연기 | 준비 동작, 인사, 깜빡임, 고개, 동물 반응 | 음성·음소 립싱크·대화 없음 |

## 영상 실험

https://github.com/quddnr0107-lgtm/taesan-animation-lab/actions/runs/40148517990

**성공 및 실제 프레임 시각 검토 완료.** 768×432, 24fps, 72프레임, 3초. 정지 이미지 64 samples, 영상 CPU 프리뷰 8 samples.

- 대표 이미지 포함 렌더: 241.43초 (약 4분 1초)
- 대표 이미지 단계: 29.61초; 이후 애니메이션 단계 약 211.82초
- 최대 RSS: 684,020 KiB (약 668.0 MiB)
- 72프레임 전체 비어 있지 않음, 프레임 간 변화, MP4 길이·프레임 수 검사 통과
- 1·40·72 프레임에서 캐릭터·동작·구도를 검토. 팔 올리기와 동물 반응 출력 확인.
- [실제 결과 MP4](003-reference-study.mp4) — 저장소에 보존. Actions 아티팩트 만료와 별개.

형태·동작·재질은 여전히 원본과 다르며 방송과 동일한 수준에 도달하지 않았다. 한국어 음성과 음소 립싱크는 없다.

## 판정

참고 작품의 색·의상·배경 구성을 따라 만든 절차형 3D 근사 실험이다. 원본과 동일한 캐릭터·애니메이션 또는 방송 수준 완성도라고 판단하지 않는다. 파일 생성 성공·자동 픽셀 검사·사람의 시각 검토를 구분한다.
