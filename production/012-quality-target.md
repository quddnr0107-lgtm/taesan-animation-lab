# 012: 품질 목표와 CPU 장면 개선

assets/quality-target-v1.png는 내장 이미지 생성 도구로 만든 정지 기준 이미지다. 기존 CPU 영상에서 생성된 프레임이 아니며 이 그림의 동영상화는 아직 수행하지 않았다.

외형 기준: 매끄러운 눈꺼풀, 통합된 볼과 입, 갈색 머리와 분홍 리본, 빨간 상의와 청록 치마, 부드러운 창가 조명, 자연스러운 미소와 손 인사.

사용자는 Runway 설치를 선택하지 않았다. 외부 영상 생성 호출은 수행하지 않는다. CPU 장면 수정은 별도 실험으로 검증하며 기준 이미지와 동등한 품질이라고 주장하지 않는다.
